**Артефакт для обсуждения, не прод-код.** Self-contained HTML на реальных данных базы авто v2
(дроп `/srv/orca/drops/car-base/`, CAS-945 / PR #146). Оболочка диалога повторяет прод v7.09
(токены `site/src/styles/tokens.css`, прогресс 7 шагов, rail на десктопе) + механики CAS-946/CAS-939.

**Публично:** https://dimkurilo.github.io/caseme-landing-preview/previews/cas954-quiz-search/

## Открыть локально

```bash
cd .vvoc/specs/2026-11-21-quiz-step1-search/prototype
python3 -m http.server 4399 --bind 127.0.0.1
# http://127.0.0.1:4399/index.html
```

Пересборка после правок шаблона: `node build.mjs` (читает дроп + `demand-top-12m.csv`, пишет `index.html`).

## Управление

Панель вариантов **свёрнута по умолчанию** (кнопка «⚙ Варианты» справа сверху) — не загромождает экран.
URL-параметры для детерминированных состояний:

| Параметр | Значения | Смысл |
|---|---|---|
| `v` | `A` (default) / `B` | Шаг 1: A — витрина + поиск; B — поиск + полный список 58 марок |
| `size` | `12` (default) / `18` / `24` | Размер витрины (топ по заказам CRM 12 мес, тай-брейк — объявления марки) |
| `sort` | `S1` / `S2` / `S3` (default) | Шаг 2: А→Я / по популярности / гибрид «Популярные + А→Я» |
| `step` | 1 / 2 / 3 / 4 | Стартовый шаг (4 — заглушка «Госномер») |
| `brand`, `model`, `gen` | имена из каталога | Предвыбор |
| `q` | строка | Поисковый запрос (`q=тигуан`) |
| `other` | строка | Раскрытое единое поле «Другая» с текстом (`other=Москвич 412 1976 года`) |
| `clean` | `1` | Скрыть кнопку панели (чистый диалог для скринов) |
| `bar` | `1` | Раскрыть панель вариантов |

## Что демонстрирует (решения владельца 22.11 + ревью GLM-5.3)

- **Витрина 12/18/24** — топ марок по заказам CRM за 12 мес. 12: всё без скролла на 375×667;
  18: «+ Другая» в первом экране, примечание скроллится; 24: «+ Другая» ниже фолда — как в текущем
  проде (23 марки + «Другая»). Состав — гипотеза для пост-запусковой проверки.
- **Поиск марки**: substring + алиасы («мерс»→Mercedes-Benz, «жигули»→Lada, «gaz»→ГАЗ) + транслит +
  fuzzy≤2 (запросы ≥5 симв.). Бейджи «транслит»/«похоже» — только прототип.
- **Поиск модели**: «тигуан»→Tiguan, «камри»→Camry, «бокс»→Dongfeng BOX. В пустом результате —
  «Не нашли? Впишите модель вручную» (кейс Sprinter 907: марка есть, модели в каталоге нет).
- **Сортировка S3**: «Популярные» (топ-6 по объявлениям av.by) + остальные А→Я; для марок с ≤10 моделями
  или <3 кандидатов с listings>0 — плоский А→Я. В проде нужен артефакт ранжирования «бренд→топ-6»
  (строгий файл listings не содержит).
- **Поколение — только если реально есть (п.3 владельца, av.by — истина)**: у новых моделей
  (Geely Cityray, Belgee X50+) шаг 3 пропускается; quiz_step_3 эмитится синтетически (паттерн CAS-939),
  воронка монотонна. У BMW X5 — 7 реальных поколений. «I ()» не рендерится никогда.
- **Единое поле «Другая» (п.4 владельца)**: «Москвич 412 1976 года» одной строкой — марка+модель+год,
  никаких трёх полей ввода. Раскрытие — механика CAS-946: top-align + автофокус + «Свернуть ×»
  (фокус возвращается на триггер). Контракт payload для единой строки фиксирует спека.
- «Не знаю точную модель» → скип поколения → шаг 4 (существующий путь CAS-939).

## Упрощения прототипа (не переносить в прод как есть)

- fuzzy ≤2 на длинных запросах может шуметь — порог/правила фиксирует спека;
- транслит символ-в-символ («тойота»→toiota) — марочные алиасы закрывают, модельные частично;
- бейджи, легенды, примечание витрины, кнопка «⚙ Варианты» — скаффолдинг обсуждения;
- шаги 4–7 — заглушка (информационная карточка);
- данные зашиты в HTML; в проде — static import строгого файла (+13 КБ gzip к острову;
  остров на лендинге client:idle) + артефакт ранжирования;
- спейсер CAS-946 (компенсация софт-клавиатуры) в прототипе заменён top-align скроллом.
