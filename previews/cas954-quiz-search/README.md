# CAS-954 — квиз шаг 1–2: витрина + поиск, сортировка моделей

Интерактивный прототип для обсуждения (не прод). Реальные данные базы авто v2
(58 марок / 1437 моделей / 3453 поколения, av.by 21.11.2026), оболочка квиза v7.09.

**Открыть:** https://dimkurilo.github.io/caseme-landing-preview/previews/cas954-quiz-search/

Панель сверху переключает:
- **Шаг 1, вариант A** — витрина 12 плиток (топ по заказам CRM за 12 мес) + поиск + «+ Другая»;
- **Шаг 1, вариант B** — поиск + полный список 58 марок с секцией «Популярные»;
- **Сортировка моделей (шаг 2):** S1 — А→Я (как в проде), S2 — по популярности (объявления av.by),
  S3 — гибрид «Популярные» топ-6 + остальные А→Я;
- **Шаги 1/2/3** — можно кликать плитки и проходить сценарий; «Далее» на шаге 3 никуда не ведёт (шаги 4–7 не реализованы).

Попробуйте поиск: «мерс», «жигули», «тигуан», «камри» (алиасы + транслит + fuzzy).
На шаге 3 у Geely Cityray — демо фикса «I ()» → «I · годы не указаны».

URL-параметры для прямых ссылок на состояния: `?v=A|B`, `?sort=S1|S2|S3`, `?step=1|2|3`,
`?brand=Volkswagen`, `?model=Passat`, `?q=тигуан`, `?clean=1` (скрыть панель прототипа).

Данные в прототипе: каталог av.by (публичный), объявления av.by (публичные), агрегированные
счётчики заказов CRM по маркам/моделям (без PII). Истина: репо `dimkurilo/auto.caseme.by`,
пакет `.vvoc/specs/2026-11-21-quiz-step1-search/`, тикет CAS-954.
